# T-E3：VS Code 个人 AI 工作流搭建指南

> 难度：⭐⭐ 中等｜类别：Quarto + AI Agent 在线书/报告  
> 核心工具：`Quarto` · `VS Code` · `GitHub Pages` · 各类 AI 插件  
> 建议人数：7～8 人｜预计完成时间：1～2 周

---

## 一、项目背景

VS Code 已经成为数据分析师最常用的代码编辑器之一，而 AI 辅助编程工具（GitHub Copilot、Continue、Cursor 等）的出现正在彻底改变工作流。然而，「工具太多、不知从哪开始」是许多人的困惑。

本题要求小组亲身测试多种 AI 工具，用 Quarto 撰写一本实用的《VS Code 个人 AI 工作流搭建指南》，发布到 GitHub Pages，供全班同学参考使用。重点是「真实体验」——必须亲自安装、测试，写出自己的使用心得，而不是照搬网络教程。

---

## 二、学习目标

完成本题后，你将能够：

- 系统评测多种 AI 编程辅助工具，形成自己的判断
- 用 Quarto 撰写图文并茂的技术指南（含截图、代码示例）
- 在 VS Code 中搭建高效的 Python 数据分析工作流
- 理解「提示词工程」在实际编程场景中的应用

## 五、核心任务说明

### 任务 1：各 AI 工具评测（每章必须包含的内容）

每位成员评测自己负责的工具时，必须完成以下标准化测试，确保各章可以横向比较：

#### 标准测试任务（每个工具都跑一遍）

```python
# 测试任务 1：代码生成
# 给 AI 的 prompt：
# 「用 akshare 获取上证指数近一年的日度数据，
#   计算 20 日移动平均线，用 matplotlib 画出来，
#   要求有中文标题、网格线、图例」
# 记录：AI 是否一次成功？需要几次修改？代码质量如何？

# 测试任务 2：报错调试
# 故意引入一个常见错误（如缺少 import、变量名拼写错误），
# 让 AI 诊断并修复，记录准确率和解释质量

# 测试任务 3：代码解释
# 给 AI 一段从网上复制的陌生代码，让它用中文解释每一行
# 评测：解释是否准确、是否通俗易懂

# 测试任务 4：代码重构
# 给 AI 一段写法低效的 pandas 代码（用循环替代向量化操作），
# 让它重构为更 Pythonic 的写法
```

#### 评测维度（每章末尾附表）

| 评测维度 | 满分 | 评分 | 说明 |

## 六、写作质量要求

本题的核心产出是「写作质量」，以下几点特别重要：

1. **真实性**：必须亲自测试，不允许只看网络教程就写。章节中的截图必须是自己的操作界面。

2. **可复现性**：读者按照你的指南操作，应该能够成功安装和使用工具。每一步必须精确。

3. **诚实评价**：如果某个工具有明显缺点（速度慢、中文差、经常出错），要如实写出来。

4. **横向比较**：附录的对比表是全书的精华，每个工具按同一标准评分，有助于读者选择。
