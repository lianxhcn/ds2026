# P03d：招聘信息文本分析——「数据分析师」市场需求画像

> **课程**：数据分析与经济决策（ds2026）｜**类型**：个人作业｜**提交物**：Jupyter Notebook + .csv 文件

---

## 任务背景

招聘信息是观察劳动力市场需求的直接窗口。一个自然的问题是：市场上的「数据分析」岗位，究竟需要什么技能？本题要求你爬取招聘平台上的相关岗位信息，从中提炼出数据分析师的市场需求画像。

顺便说一句，这道题的分析结论直接和你们自己的就业相关——做得认真一点没有坏处。

**数据来源**：Boss 直聘（zhipin.com）、智联招聘、前程无忧等，任选一个

**核心训练点**：动态网页爬取、正则表达式处理薪资字符串、关键词提取、岗位需求可视化

---

## 任务一：数据获取

以「数据分析」为关键词，爬取至少 **100 条**招聘信息，提取以下字段，保存为 `jobs_data_analyst.csv`。

| 字段 | 说明 |
|---|---|
| `job_title` | 职位名称 |
| `company` | 公司名称 |
| `city` | 工作城市 |
| `salary_raw` | 薪资原始文本（如「15-25k·13薪」） |
| `salary_min` | 最低月薪（千元/月，从 salary_raw 中解析） |
| `salary_max` | 最高月薪（千元/月，从 salary_raw 中解析） |
| `education` | 学历要求 |
| `experience` | 工作经验要求 |
| `job_desc` | 岗位描述正文 |

> 需要说明的是，各平台对自动化爬取均有限制，建议加入 `time.sleep()`，并优先尝试平台的公开接口或移动端接口。

---

## 任务二：数据清洗

- 用正则表达式解析 `salary_raw`，从「15-25k·13薪」「20-30K」等格式中提取 `salary_min` 和 `salary_max`，统一单位为千元/月
- 统一城市名称，例如「上海」与「上海市」合并
- 处理缺失值，说明你的决策
- 从 `job_desc` 中提取技能关键词（Python / SQL / Excel / R / Tableau / Power BI 等）

---

## 任务三：分析与可视化

至少完成以下 **3 项**：

| 分析维度 | 可视化建议 |
|---|---|
| 技能关键词词频 | 词云 或 词频条形图（Top 15） |
| 城市分布 | 横向条形图——哪个城市需求最多？ |
| 学历要求分布 | 饼图 或 条形图 |
| 薪资与城市 / 学历的关系 | 箱型图对比 |
| 职位名称词频 | 词云——岗位命名有哪些规律？ |

每张图需有标题、坐标轴标签和数据来源注释。
