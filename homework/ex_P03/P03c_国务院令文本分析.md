# P03c：国务院令文本分析——从政策文件到结构化数据

> **课程**：数据分析与经济决策（ds2026）｜**类型**：个人作业｜**提交物**：Jupyter Notebook + .csv 文件 + 图形文件

---

## 任务背景

国务院令（国令）是国务院以行政法规形式发布的规范性文件，截至目前已发布约 470 份，覆盖经济、环境、社会保障、市场监管等各个领域。这批文件跨越数十年，是观察中国政策议程演变的难得文本样本。

本题要求你将这批政策文本转化为结构化数据，并围绕发布时间、文本长度、关键词演变等维度进行分析。重点不是判断政策好坏，而是训练「把真实中文政策文本转化为可分析数据」的完整流程。

**数据来源**：中国政府网国务院政策文件库（[sousuo.www.gov.cn](https://sousuo.www.gov.cn/zcwjk/policyDocumentLibrary)）

**核心训练点**：政府网站爬取（或文本读取）、中文分词、TF-IDF 关键词、多时期文本比较

## 任务一：数据获取

**两种方案可选，任选其一**：

- **方案 A（推荐）**：使用教师提供的初始数据 `policy_guoling_raw.csv`，重点完成后续文本分析任务
- **方案 B（加分）**：自行爬取国务院政策文件库中的「国令」列表，提取每份文件的标题、日期、链接及正文，代码须可复现

最终整理为一张结构化表格，每行对应一份国令，包含以下字段：

| 字段 | 说明 | 类型 |
|---|---|---|
| `title` | 文件标题 | 基本字段 |
| `doc_no` | 文号（国务院令第 ××× 号） | 基本字段 |
| `date` | 发布日期 | 基本字段 |
| `year` | 发布年份（从 date 中提取） | 基本字段 |
| `url` | 原文链接 | 基本字段 |
| `text` | 正文内容 | 基本字段 |
| `text_len` | 正文字数 | 分析字段 |
| `n_articles` | 条款数量（若能提取） | 分析字段 |
| `keywords_tfidf` | TF-IDF 关键词（Top 10） | 分析字段 |

## 任务二：数据清洗

## 任务三：文本分析

将样本按以下四个时期划分，分别进行分析：

| 时期 | 范围 |
|---|---|
| 第一阶段 | 2000 年以前 |
| 第二阶段 | 2000—2009 年 |
| 第三阶段 | 2010—2019 年 |
| 第四阶段 | 2020 年以后 |

**须完成以下全部内容**：

**3.1 时间分布**：各年份发布国务院令数量的折线图或柱状图

**3.2 文本长度趋势**：各时期平均文本字数的变化（箱型图或折线图）。国令的平均篇幅是否在增长？

**3.3 关键词比较**：各时期 TF-IDF Top 10 关键词的对比展示（词云、热力图或分组条形图均可）
