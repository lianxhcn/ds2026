# P03a：安泰经管学院教师名录爬取与分析

> **课程**：数据分析与经济决策（ds2026）｜**类型**：个人作业｜**提交物**：Jupyter Notebook + .csv 文件

---

## 任务背景

上海交通大学安泰经济与管理学院是国内顶尖商学院之一。本题要求你从其官网爬取在职教师名录，整理为结构化数据，并对师资队伍的职称结构、研究方向等进行可视化分析。

数据来源：[https://www.acem.sjtu.edu.cn/faculty/team.html](https://www.acem.sjtu.edu.cn/faculty/team.html)

**核心训练点**：`requests` + `BeautifulSoup` 基础爬虫、数据清洗、描述性统计与可视化

---

## 任务一：数据获取

使用 `requests` + `BeautifulSoup` 爬取安泰学院在职教师页面，提取以下字段，保存为 `acem_faculty.csv` 和 `acem_faculty.md` 两种格式。

| 字段 | 说明 |
|---|---|
| `name` | 教师姓名 |
| `title` | 职称（教授 / 副教授 / 讲师等） |
| `department` | 所属系或研究院 |
| `research_areas` | 研究方向（原始文本） |
| `profile_url` | 个人主页链接 |

---

## 任务二：数据清洗

- 统一职称命名，例如「教授」与「Professor」合并为同一类别
- 处理缺失值，并在 Notebook 中说明你的决策（是删除还是保留？为什么？）
- 从研究方向文本中提取关键词，可以用 `jieba` 分词，也可以用简单字符串匹配

---

## 任务三：描述性分析与可视化

至少完成以下 **3 项**：

| 分析维度 | 可视化建议 |
|---|---|
| 职称结构 | 饼图 / 横向条形图 |
| 各系教师人数分布 | 横向条形图 |
| 研究领域词频 | 词云 或 词频条形图（Top 20） |
| 博士毕业院校分布（若能获取） | 条形图 |

每张图需有标题、坐标轴标签和数据来源注释。
