# 示例选题三：广州哪里开咖啡馆最容易活下去？

> **示例说明**：这是一份「研究提案」，展示选题思路和分析规划。  
> 这个选题刻意选得生活化一些，用来说明：好问题不一定来自金融或政策，日常生活里同样有值得认真研究的问题。  
> ds2026 · 第二次小组作业示例

---

## 一、我们在帮谁解决什么问题

**决策主体：打算在广州开一家独立咖啡馆的创业者**

小组有成员一直有开咖啡馆的想法，但又听说「十家咖啡馆九家亏」。真的是这样吗？不同区域的差距有多大？选错了地方，再好的咖啡豆也救不了你。

这是一个非常具体的决策问题：**在广州，选哪个区、哪种商圈开一家独立咖啡馆，生存概率最高？**

这个问题对创业者来说是真实的生死抉择，但大多数人做决策时靠的是「感觉这里人多」或者「这里租金便宜」，很少有人系统地看过数据。

---

## 二、背景：广州咖啡市场发生了什么？

### 行业背景

过去五年，中国咖啡市场经历了爆发式增长，但也伴随着剧烈的竞争淘汰。

- **连锁品牌下沉**：瑞幸、库迪把咖啡价格打到 9.9 元，独立咖啡馆的价格优势消失
- **开店数量激增**：2020—2023 年广州咖啡馆数量翻倍，但关店速度也在加快
- **消费习惯改变**：工作日外卖咖啡需求旺盛，周末打卡型消费支撑了部分精品咖啡馆
- **租金分化**：核心商圈租金高企，但流量也更稳定；居民区租金低，但能否形成稳定客群存在不确定性

这些变化共同构成了「现在在广州开独立咖啡馆」这个决策的真实背景。不了解这个背景，无法判断选址的逻辑。

### 我们真正想搞清楚的问题

广州哪些区域的咖啡馆密度已经很高（竞争激烈）？哪些区域还有空白？高密度区的咖啡馆存活率是高还是低（高密度 = 市场成熟，还是高密度 = 血海）？不同类型商圈（写字楼、大学城、居民区、旅游区）的咖啡馆经营规律有何不同？

---

## 三、核心研究问题

**问题一（密度地图）**  
广州各区的咖啡馆数量和密度如何分布？哪些街道已经「卷」到饱和，哪些还有空间？

**问题二（存活率）**  
过去 3 年，不同区域、不同类型商圈的咖啡馆关店率有何差异？高流量区域是否意味着更高的存活率？

**问题三（客群画像）**  
不同商圈类型（写字楼 CBD、大学城、老城居民区、商业综合体）的咖啡馆，在评分、评论数量、营业时间上有什么规律性差异？这些差异能说明什么样的客群需求？

**问题四（竞争格局）**  
独立咖啡馆和连锁品牌（瑞幸、星巴克、Manner 等）在空间上是什么关系？独立咖啡馆开在连锁品牌旁边，是「借势」还是「送死」？

---

## 四、我们预期发现什么

- 天河区（尤其是 CBD 和大学城周边）咖啡馆密度最高，但存活率不一定最低——因为消费需求也最旺盛，能支撑更高的密度
- 越秀、荔湾的老城区有一批存活年限较长的独立咖啡馆，客群稳定但规模有限，适合「小而美」的定位
- 写字楼商圈的咖啡馆工作日流量高、周末流量低，评论集中在「速度快、适合办公」；大学城周边则评论更多集中在「空间好、适合学习」——两种商圈对应两种完全不同的产品逻辑
- 连锁品牌附近的独立咖啡馆并没有系统性更低的评分，说明差异化定位可以在连锁品牌旁边活下去

---

## 五、数据需求

这个课题的有趣之处在于：数据完全来自公开平台，不需要任何特殊资源。

| 需要什么数据 | 从哪里获取 | 具体内容 |
|------------|-----------|---------|
| 广州全部咖啡馆的位置、评分、评论数 | 高德地图 API / 大众点评 | 名称、坐标、评分、人均消费、评论数、营业时间 |
| 咖啡馆的开业时间和关店信息 | 大众点评「已关闭」标签 / 天眼查 | 识别存活 vs 关闭，估算存活时长 |
| 各区域的人口密度和写字楼分布 | 广州统计局 / 高德 POI 数据 | 构造「商圈类型」标签（CBD/居民区/大学城等）|
| 连锁品牌门店位置 | 高德地图 API | 瑞幸、星巴克、Manner、Tims 等 |

**获取方式说明**：高德地图开放平台（<https://lbs.amap.com/>）提供免费 API，可以按关键词和城市批量获取 POI（兴趣点）数据，包括坐标、评分、评论数等字段，这是整个分析的核心数据来源。大众点评有反爬机制，建议以高德为主，大众点评作为补充验证。

---

## 六、分析思路与图表规划

**第一步：绘制广州咖啡馆密度地图**

用高德 API 抓取广州所有带「咖啡」关键词的 POI，在地图上标注位置，用热力图展示密度分布。这是整个分析最直观的一张图——让人一眼看到哪里「卷」、哪里还有空间。

**第二步：商圈类型分类与对比**

根据每个咖啡馆周边 500 米内的写字楼数量、高校数量、住宅小区数量，把咖啡馆分为四类商圈（CBD 写字楼型、大学城型、居民社区型、旅游景区型）。然后对比四类商圈在评分、评论数、人均消费上的分布差异，用箱线图或分组柱状图展示。

**第三步：存活率分析**

在大众点评或天眼查上识别「已关闭」的咖啡馆，计算不同区域、不同商圈类型的关店比例。这是最有价值的一张图：同样是开咖啡馆，在不同地方失败率相差多少？

**第四步：与连锁品牌的空间关系**

抓取瑞幸、星巴克、Manner 的门店坐标，计算每家独立咖啡馆距离最近连锁品牌的距离，然后分析「距离连锁品牌越近的独立咖啡馆，评分和评论数是否更高或更低」。

**第五步：综合选址建议**

把前面几步的发现汇总，给出一个基于数据的选址建议框架：什么样的位置组合（区域 + 商圈类型 + 与连锁品牌的关系）在历史上存活率更高、评分更好。

---

## 七、这个选题有什么值得注意的局限性

**数据时效性**：高德和大众点评的数据是当前快照，开业时间和关店时间难以精确获取，存活率的估算会有误差。

**评分不等于盈利**：评分高的咖啡馆不一定盈利，只是用户满意度的代理指标。真正的财务数据无法从公开渠道获取。

**因果关系**：我们能发现「某类商圈的存活率更高」，但无法确认是因为商圈本身，还是因为选择这类商圈的创业者本来就更有经验。观察到的相关性不等于因果。

**广州的结论不能直接推广**：广州的消费习惯、租金水平、人口结构都有自己的特点，这份分析的结论不能直接套用到北京或成都。

---

## 八、为什么这个选题是好选题？

在这里多说几句，帮助理解「好选题的逻辑」：

这个选题**决策主体非常具体**——打算创业开咖啡馆的人。他们面临真实的金钱风险，需要的是「哪里开更容易活」这种可操作的结论，而不是「咖啡市场很有潜力」这种废话。

**背景可以说得很清楚**——近年连锁品牌的扩张、租金变化、消费习惯转变，这些都有数据可以描述，不是感性印象。

**数据完全可得且有趣**——高德 API 是免费的，数据抓取本身就是一次完整的爬虫练习；数据可视化后（尤其是地图）天然有视觉冲击力，适合展示。

**结论对真实决策有价值**——分析结果虽然有局限，但比「我感觉这里人多」要靠谱得多，对创业者有实际参考意义。

这个选题不「高大上」，但它符合一个好研究的所有基本要素。
